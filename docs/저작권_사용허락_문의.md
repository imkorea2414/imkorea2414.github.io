# 저작권 사용 허락 문의 자료 (2026-11-19)

원전 훈련서의 저작권자(저자 또는 승계인)와 출판사에 사용 허락을 묻기 위한 자료다. **이 문서는 공개 저장소에 있으므로 원전 문장을 옮기지 않고 쪽수와 요지만 적는다.**

> 이 문서의 "허락이 필요해 보임" 같은 판단은 법률 자문이 아니다. 최종 판단은 권리자 답변이나 저작권 전문가(한국저작권위원회 상담 등)의 의견으로 한다.

## 1. 현재 상태

| 항목 | 상태 |
|---|---|
| 책 제목·저자명·출판사명 | 앱 화면·설치 정보·스토어 설명·스크린샷에서 모두 뺐다 (B판, 2026-11-19). 내부 개발 문서의 출처 표기는 그대로 |
| B판의 의미 | **표시 방식에 대한 결정일 뿐이다.** 훈련 틀·시간표·인용 등 원전 요소는 그대로 쓰고 있으므로, 제목을 뺐다고 사용 허락 문제가 해결되지 않는다 |
| 공개 출시 | 허락 또는 문제없다는 전문가 판단이 있기 전까지 보류 (비공개 테스트만) |
| 권리자 연락처 | **확보하지 못함** (책에 연락처가 보이지 않음). 아래 4장의 경로로 찾는다 |
| 문의 전에 정리할 것 | 공개 저장소의 옛 커밋 기록에 원전 스캔 이미지와 본문 5줄이 남아 있다. 권리자가 저장소를 보게 될 수 있으므로 **Git 기록 재작성(승인 대기)을 문의 전에 끝내는 것을 권한다** (`docs/최종_병합_및_실기기_테스트_계획.md` 4장) |

## 4. 권리자 연락 경로 (확인한 연락처 없음)

1. 책의 판권면(맨 뒤쪽): 발행처 주소·전화, 발행 연도·판. 제공된 스캔의 저작권 표시 연도(2004, 1978)가 1989년과 달라 **판·인쇄 연도부터 확인**한다.
2. 한국저작권위원회: 저작권 등록부 검색, 권리자 찾기·상담 (전화·온라인 상담).
3. 국립중앙도서관 서지 정보: 같은 책의 다른 판·출판사 확인.
4. 출판사가 문을 닫았다면 저작권이 저자(또는 상속인)에게 있는지 위 2·3으로 확인.
5. 저자 소속 대학·학회가 확인되면 그 경로로 연락처를 묻는다.

## 7. 허락을 받지 못했을 때: 독립 훈련 모형으로 대체하는 방안

### 7-1. 먼저 알아 둘 점

- 대체하면 **서비스의 성격이 바뀐다.** 지금의 원칙은 "원전이 서비스의 중심"(CLAUDE.md 1장)이다. 원전 요소를 빼면 "원전 훈련 과정을 화면에서 따라 하는 앱"이 아니라 "이 서비스가 설계한 시선 이동 훈련 앱"이 된다. 이 방향을 택할지는 사용자 결정이다.
- 대체판에서도 **다른 속독 사이트의 훈련법을 가져오지 않는다** (CLAUDE.md 1장). 대체 모형은 이 서비스가 직접 설계하고, 모든 안내에 `설계` 표시를 단다.
- 원전 훈련법이라고 하거나, 원전 저자의 방법을 바탕으로 했다고 하지 않는다. 효과를 주장하지 않는다.
- 법률 참고 (확인하지 않은 일반론): 저작권은 보통 아이디어·방법 자체보다 구체적인 표현(그림, 글, 표의 선택·배열)을 보호한다고 알려져 있다. 그러나 이 앱의 어떤 요소가 표현에 해당하는지는 **전문가 확인이 필요**하다. 이 일반론을 근거로 원전 요소를 그대로 쓰지 않는다.

### 7-3. 독립 모형 설계 원칙

1. **출발점은 화면 조건:** 태블릿·휴대폰 화면 비율, 화면 보정으로 얻은 실제 mm, 시선 거리. 원전 그림을 변형하는 방식(원 개수만 바꾸기 등)은 쓰지 않고, 화면 조건에서 새로 정한다.
2. **훈련 단계와 시간:** 이 서비스가 정한 단계와 시간(예: 짧게 시작해 같은 시간을 두 번 마치면 늘리는 기존 "시간 사다리" 방식)을 쓰고, 모든 값에 `설계`·`추정` 표시를 단다.
3. **측정:** 1분 읽기 속도(글자 수)와 문항 정답률만 쓴다. 9점 척도·R.E.I.처럼 원전에서 온 지표는 뺀다.
4. **안내문:** 원전 표현을 다듬은 문장이 아니라 처음부터 새로 쓴다. 원전 인용·쪽수는 모두 뺀다.
5. **검토:** 대체판도 출시 전에 권리 관계를 다시 확인한다 (원전과 지나치게 비슷한 배치가 남지 않았는지).
