# 실기기 최종 테스트 (순서와 합격 기준)

기기 한 대에 약 40분. 위에서부터 순서대로 하면 된다. 결과는 맨 아래 표에 ○ / × / 해당 없음으로 적고, ×는 화면 사진을 남긴다.

## 0. 시작 전 준비 (5분)

| 할 일 | 방법 | 확인 |
|---|---|---|
| 웹 버전 확인 | 앱을 열고 대시보드 맨 아래 문구를 본다 | **"…독립 서비스이며, 원저자·출판사와 공식적인 관계가 없습니다…"** 가 보이면 최신(최종 병합 뒤) 버전. "프로토타입입니다"가 보이면 옛 버전이라 테스트를 미룬다 |
| 기기 정보 적기 | 설정 → 휴대전화(태블릿) 정보 | 기종, OS 버전, Chrome/Safari 버전 |
| Android 앱 설치 | GitHub → Actions → Android app bundle → 최신 실행 → Artifacts에서 `speedread-android-N` 내려받기 → 압축 풀기 → `app-release.apk` 설치 | 설치됨 (Play 비공개 테스트가 시작됐으면 Play 스토어에서 설치) |
| 화면 자동 꺼짐 시간 | 설정 → 디스플레이 | 30초~1분으로 두기 (9번 확인용) |

기기별로 하는 항목: Android 휴대폰·태블릿 = 1~14 전부. iPad = 2~14 (Safari 탭 한 번, 홈 화면 앱 한 번). MacBook = 2~4, 6, 8, 10~14 (Safari, Chrome 각각).

## 1. 순서와 합격 기준

| # | 순서 | 합격 기준 |
|---|---|---|
| 1 | Android 앱 아이콘을 눌러 실행 | 3초 안에 대시보드가 뜬다. **위쪽에 주소창이 없다** (Play에서 설치한 앱은 앱 서명 키 지문을 넣은 뒤에 확인) |
| 2 | 첫 화면에서 "이어서 하기"(또는 첫 훈련) → 화면 보정 | 실제 신용카드를 화면 사각형에 댔을 때 −/+로 크기를 맞출 수 있다. 화면이 좁으면 카드가 세로로 서 있다. 저장 뒤 훈련 안내 화면으로 간다 |
| 3 | 훈련 안내 화면에서 시간·횟수·세기 버튼을 하나씩 누른다 | 손가락으로 한 번에 눌리고, 옆 버튼이 잘못 눌리지 않는다. 고른 버튼이 검게 바뀐다 |
| 4 | "시작" → 도입에서 강조된 원을 손가락으로 짚기 → 훈련 | 원이 일정한 박자로 옮겨 간다. 끊기거나 멈추지 않는다 |
| 5 | (휴대폰) 기기를 **가로**로 돌린 채 훈련 중 빠르기 −/+ 를 엄지로 누른다 | 한 번에 눌리고 빠르기 숫자가 바뀐다. 훈련 틀이 잘리지 않는다 |
| 6 | 훈련 중 일시정지 버튼 → 다시 시작 / (Mac) 훈련 중 Esc | 바로 멈추고 이어진다. Mac에서 Esc로 전체 화면이 풀리면 일시정지 화면이 뜬다 |
| 7 | (iPad) 작은 버튼(빠르기 −/+, 언어 EN)을 빠르게 두 번 누른다 | 화면이 확대되지 않는다 |
| 8 | 훈련을 끝까지 → 반응 점검 화면 | 고른 버튼이 파란색과 ✓ 로 분명히 구분된다. 깜박임 안내에 "이 기기 안에만 저장… 보내지 않습니다"가 보인다 |
| 9 | 훈련을 자동 꺼짐 시간보다 오래 한다 (3분 이상 선택) | 훈련 중에는 화면이 꺼지지 않는다 (iPad 홈 화면 앱은 iPadOS 18.4 이상만) |
| 10 | Training → "독서활동 R.M." 시작 (휴대폰은 **세로**로) | 아래 정보 칸이 위 3칸 + 아래 빠르기 칸으로 보이고, 빠르기 + 버튼이 화면 안에 있다. 손가락으로 막대를 따라갈 수 있다 |
| 11 | Test → 1분 형성평가 → 1분 읽기 → 마지막 낱말 누르기 → 이해도(9점) 고르기 → 문항 답하기 | 결과 화면에 속도·문항 정답률·R.E.I.가 나온다 (R.E.I. = 속도 × 9점 × 0.1). Progress 표에 기록이 생긴다. 11/19 이전 기록이 있으면 R.E.I. 옆에 `*`가 붙는다 |
| 12 | Progress → "파일로 내보내기" → (브라우저·앱 설정에서 사이트 데이터 삭제) → 앱 다시 열기 → "파일에서 가져오기" | 내보낸 파일이 저장된다. 가져온 뒤 Day·기록이 그대로 돌아온다 |
| 13 | 인터넷이 될 때 `https://imkorea2414.github.io/privacy.html` 을 한 번 연다 → **비행기 모드** → 앱 실행 | **앱(대시보드)이 열린다.** 개인정보처리방침이 열리면 실패 (예전 오류) |
| 14 | 비행기 모드 그대로 개인정보처리방침 주소를 연다 → 비행기 모드 끄고 앱 다시 실행 | 오프라인에서도 개인정보처리방침이 열린다. 다시 연결하면 앱이 정상으로 열린다 |

추가로 볼 것 (한 기기에서만): 언어 EN ↔ 한국어, 테마 자동/밝게/어둡게 전환 뒤 글자가 잘 보이는지. 비행기 모드에서도 글꼴이 바뀌지 않는지: 앱을 **처음 설치해 한 번만 연 뒤** 비행기 모드로 Curriculum·Test·Progress를 열어 본다 (숫자·제목 글꼴이 온라인 때와 같아야 함). Curriculum에 "참고 목표"·"정리 시간"이 보이는지.
