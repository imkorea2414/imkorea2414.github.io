# 테스터 모집·안내 자료

Google Play 규칙: 개인 개발자 계정은 **테스터 12명 이상이 14일 동안 계속 참여**해야 출시 신청을 할 수 있다. 중간에 빠지는 사람을 생각해 **15~20명**을 모은다.

`[ ]`는 보내기 전에 채운다.

---

## 1. 모집 메시지 (카카오톡·문자용)

```
안녕하세요! 제가 만든 속독 훈련 앱 "속독 트레이닝"의 출시 전 테스트를 도와주실 분을 찾고 있어요.

· 기간: [11월 _일]부터 14일 동안 (앱을 지우지 않고 두기만 하면 돼요)
· 필요한 것: 안드로이드 폰이나 태블릿, Gmail 주소
· 할 일: 설치하고, 시간 날 때 하루 10분쯤 훈련해 보기 (매일 안 해도 괜찮아요)
· 개인정보: 회원가입 없고, 기록은 기기 안에만 저장돼요

도와주실 수 있으면 Play 스토어에 쓰는 Gmail 주소를 알려 주세요. 🙏
```

(아이폰만 있는 분은 Play 테스트에는 참여할 수 없어요. 대신 웹 주소 https://imkorea2414.github.io/ 로 써 보고 의견을 줄 수 있어요. 이 경우 12명 숫자에는 들어가지 않아요.)

## 2. 초대 메시지 (Gmail을 받은 뒤)

```
테스트에 참여해 주셔서 고마워요! 아래 순서대로 해 주세요.

1) 이 링크를 Play 스토어에 쓰는 Gmail 계정으로 열어 주세요 → [참여 링크]
2) "테스터 되기"를 누르고, 이어서 나오는 "Google Play에서 다운로드"를 눌러 설치해 주세요
3) 앱을 열면 "오늘 훈련" 순서대로 하면 돼요. 처음에 화면 보정(카드로 화면 크기 맞추기)이 나와요
4) [11월 _일]까지 14일 동안 앱을 지우지 말아 주세요

불편한 점이나 이상한 점은 언제든 저에게 알려 주시거나 이 양식에 적어 주세요 → [의견 양식 링크]
```

## 3. 중간 안부 메시지 (5일째, 10일째)

```
테스트 [5]일째예요. 써 보시면서 불편한 점 있었나요?
특히 궁금한 건 이거예요:
· 훈련 중에 원 따라가기가 너무 빠르거나 느리지 않은지
· 책장 넘기기(오른쪽 아래 탭)가 자연스러운지
· 화면 크기가 작아서 보기 힘들지 않은지
한 줄이라도 좋아요. 그리고 14일 끝날 때까지 앱은 지우지 말아 주세요!
```

## 4. 의견 양식 문항 (Google 설문지 등에 옮겨 쓰기)

1. 쓰신 기기 (예: 갤럭시 S23, 갤럭시 탭 S9) — 단답
2. 며칠쯤 써 보셨나요? — 1~2일 / 3~6일 / 7일 이상
3. 설치는 어렵지 않았나요? — 쉬웠다 / 조금 헷갈렸다 / 어려웠다 (+ 어떤 점)
4. 화면 보정(카드로 크기 맞추기)은 이해하기 쉬웠나요? — 5점 척도
5. 훈련 중 원의 빠르기는 어땠나요? — 너무 느림 / 적당 / 너무 빠름
6. 책장 넘기기(오른쪽 아래 탭)는 자연스러웠나요? — 5점 척도
7. 훈련 중 눈이 많이 불편했나요? 어떤 점이었나요? — 서술
8. 1분 측정 뒤 문항은 읽은 내용과 맞았나요? — 예 / 아니요 / 잘 모르겠다
9. 글자가 깨지거나, 화면이 잘리거나, 버튼이 안 눌린 적이 있나요? — 서술 (가능하면 화면 캡처)
10. 가장 좋았던 점 / 가장 고쳤으면 하는 점 — 서술
