## 1. 설치와 실행

- ☐ 설치 후 앱 서랍에 "속독 트레이닝" 아이콘이 보인다
- ☐ 실행하면 밝은 회색 시작 화면(splash) 뒤 대시보드가 뜬다
- ☐ **화면 위에 주소창(imkorea2414.github.io)이 보이지 않는다** ← 앱-웹 연결(assetlinks) 확인. 보이면 아래 "문제 해결" 참고

- ☐ 두 번째 실행 시간: ____초
- ☐ 최근 앱 목록에서 밀어 종료 → 다시 실행해도 정상

## 2. 메뉴와 버튼

- ☐ 아래 탭: Dashboard / Progress / Curriculum 이 각각 열린다
- ☐ Training / Test 탭은 흐리게 눌리지 않는다 (**정상**: 아직 비활성으로 둔 메뉴)
- ☐ 오른쪽 위 테마(Auto/Light/Dark) 버튼으로 밝은/어두운 화면이 바뀐다
- ☐ 언어 버튼(한국어/English)으로 모든 글자가 바뀐다
- ☐ 대시보드 "오늘 훈련" 목록의 각 항목 버튼이 열린다

## 3. 화면 보정 (처음 훈련 시작 때)

- ☐ 신용카드(85.6mm)를 화면에 대고 맞추는 과정이 손가락으로 조절된다
- ☐ 저장 후 "책 시야각의 N%" 같은 안내가 납득할 만하다 (휴대폰은 100% 미만이 정상)

## 4. 훈련 (Day 1 기본단계 A-I부터)

- ☐ 시작하면 전체 화면이 되고 3·2·1 카운트다운이 나온다
- ☐ 도입: 파란 원을 손가락으로 짚으며 따라갈 수 있다
- ☐ 훈련: 원이 박자에 맞춰 움직인다, −/+ 로 빠르기가 바뀐다
- ☐ **화면을 만지지 않고 3분 동안 두어도 화면이 꺼지거나 어두워지지 않는다**
- ☐ 일시정지 버튼 → 다시 시작 / 훈련 끝내기 가 동작한다
- ☐ 훈련 중 홈 버튼으로 나갔다 돌아오면 일시정지 상태로 되돌아온다
- ☐ 위 상황 뒤 다시 시작해서 3분 동안 화면이 꺼지지 않는다 (수정 반영 후 확인)
- ☐ 훈련 중 전화·알림이 와도 앱이 멈추지 않고 일시정지된다
- ☐ 끝나면 반응 점검(깜박임 횟수 등) → 결과 화면이 나온다
- ☐ 제1단계 B, 제2단계 C(두 쪽 펼침): 쪽이 바뀌면 원이 멈추고 **오른쪽 아래를 탭**하면 넘어간다
- ☐ 휴대폰을 가로/세로로 돌려도 원 배치가 다시 맞춰진다
- ☐ 가로로 돌렸을 때 훈련 원이 충분히 크게 보이고, 아래 TIME·ROUND 등 정보 칸이 한 줄로 보인다 (10/29 수정)
- ☐ Training 탭에서 아무 훈련이나 열 수 있고, Test 탭에서 1분 측정·시각능력 측정을 열 수 있다
- ☐ Progress 아래 "파일로 내보내기"로 백업 파일이 저장되고, "파일에서 가져오기"로 되살릴 수 있다
- ☐ 세로 화면에서 "기기를 가로로 돌리면 원이 더 크게 보입니다" 안내가 보인다 (정상)

## 5. 측정·독서

- ☐ 1분 형성평가: 글 읽기 → 문항 6개 → 결과(속도·이해도·R.E.I.)가 나온다
- ☐ 독서활동 R.M.: 글줄이 표시되고 빠르기 조절·일시정지가 된다
- ☐ 시각능력 1분 측정: 원 세기 후 결과 숫자가 나온다

## 6. 진행과 저장

- ☐ 오늘 훈련을 모두 마치면 다음 Day가 열린다
- ☐ Progress 화면에 독서 속도·시각능력·훈련 시간이 기록된다
- ☐ 앱 종료 → 다시 실행해도 기록과 Day가 그대로다
- ☐ 휴대폰 재부팅 후에도 기록이 그대로다
- ☐ (알아 두기) 기록은 휴대폰의 **Chrome 저장공간**에 들어간다. Chrome 설정에서 "인터넷 사용 기록 삭제 → 쿠키 및 사이트 데이터"를 지우면 앱 기록도 지워진다. 테스트 중에는 지우지 마세요.

## 7. 화면 크기와 글자

- ☐ 한글이 깨지지 않는다 (네모 □ 나 물음표가 없다)
- ☐ 글자가 화면 밖으로 잘리거나 겹치지 않는다 (특히 Curriculum의 표, Progress의 그래프)
- ☐ 가로로 스크롤되는 화면이 없다
- ☐ 휴대폰 설정 → 글자 크기를 크게 했을 때도 버튼이 눌리고 글이 읽힌다
- ☐ 태블릿이 있으면 같은 항목을 태블릿에서도 확인

## 8. 뒤로 가기

- ☐ Progress/Curriculum에서 뒤로 → 대시보드로 온다
- ☐ 대시보드에서 뒤로 → 앱이 닫힌다
- ☐ 훈련·읽기·측정 중 뒤로 → 나가지 않고 **일시정지**된다 (실수로 끊기지 않게 한 설계)
- ☐ 일시정지 화면에서 "훈련 끝내기"를 눌러야 결과로 나간다

## 9. 인터넷 연결

- ☐ 인터넷이 켜진 상태로 한 번 실행한 뒤 → 비행기 모드 → 앱 실행: 정상으로 열린다
- ☐ 비행기 모드에서 훈련·측정·기록 저장이 모두 된다
- ☐ 비행기 모드에서 개인정보처리방침 링크가 열린다
- ☐ 설치 직후 **한 번도 실행하지 않은 상태**로 비행기 모드 실행 → 오류 화면이 나온다 (정상: 첫 실행은 인터넷이 필요)
- ☐ 비행기 모드 해제 후 다시 실행하면 정상

## 문제 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| "출처를 알 수 없는 앱" 차단 | 기본 설정 | 설치하려는 앱(파일·Chrome)에 "이 출처 허용"을 켠다 |
| "앱이 설치되지 않았습니다" | 같은 이름의 다른 서명 앱이 이미 있음, 또는 파일이 덜 받아짐 | 기존 "속독 트레이닝"을 지우고 다시 설치 / 다시 내려받기 |
| "패키지를 파싱하는 중 문제" | zip을 풀지 않았거나 파일 손상 | zip을 풀어 `.apk`만 설치. `.aab`는 설치 파일이 아님 |
| Play 프로텍트 경고 | Play에 등록 전 앱이라 처음 보는 앱으로 판단 | "세부정보 → 무시하고 설치" (내가 만든 앱이므로 안전) |
| 위에 주소창이 보임 | 앱-웹 연결 확인 실패 | ① Chrome을 최신으로 업데이트 ② 아래 확인 주소를 휴대폰 Chrome으로 열어 지문이 나오는지 확인 ③ 앱 삭제 후 재설치 |
| 흰 화면만 보임 | 첫 실행인데 인터넷이 없음 | 인터넷 연결 후 다시 실행 |
| 화면 내용이 옛날 그대로 | 이전 버전이 저장(캐시)됨 | 앱을 완전히 종료 후 두 번 다시 실행 |

앱-웹 연결 확인 주소 (휴대폰이나 PC 브라우저로 열기):

- https://imkorea2414.github.io/.well-known/assetlinks.json → `36:A0:CB:80:…:5C:A8` 이 보여야 함
- https://digitalassetlinks.googleapis.com/v1/statements:list?source.web.site=https://imkorea2414.github.io&relation=delegate_permission/common.handle_all_urls → `io.github.imkorea2414.speedread` 가 보여야 함

참고: 이 확인은 **직접 설치한 APK(업로드 키 서명)** 기준이다. Play에 올린 뒤에는 Google 앱 서명 키 지문을 assetlinks.json에 추가해야 Play 설치본에서도 주소창이 사라진다.
