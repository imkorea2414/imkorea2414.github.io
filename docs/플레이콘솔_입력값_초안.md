- 회원가입·로그인 없음. 서버로 보내는 데이터 없음. 기록은 기기 안(Chrome 저장공간)에만 있음
- 광고 없음, 분석 도구 없음, 결제 없음
- Android 권한 요청 없음 (위치·카메라·마이크·연락처·알림 모두 없음), 광고 ID 사용 안 함

- 사용자끼리 대화·공유 기능 없음
- 건강·의료 기능 아님 (시력 개선 등 효과를 주장하지 않음)

## 3. 비공개 테스트 시작

1. **테스트 및 출시 → 테스트 → 비공개 테스트 → 트랙 만들기** (이름 예: `closed`)
2. **국가/지역:** 대한민국 (해외 테스터가 있으면 그 나라도 추가)
3. **테스터:** 이메일 목록 만들기 → 테스터 Gmail 주소 붙여 넣기 (쉼표로 구분)
4. **의견 URL 또는 이메일:** 문의 이메일
5. **새 버전 만들기**
   - 앱 서명: **Google에서 생성한 앱 서명 키 사용** (기본값)
   - App Bundle: GitHub Actions 최신 빌드의 `app-release.aab`
   - 버전 이름: `1.0.0`
   - 출시 노트 (한국어):
     ```
     <ko-KR>
     첫 비공개 테스트 버전입니다.
     - 『과학적 속독법』 훈련 과정을 화면에서 따라 하는 48일 과정
     - 1분 독서 측정과 이해도 문항
     - 훈련 기록은 기기 안에만 저장됩니다
     </ko-KR>
     ```
6. **검토로 이동 → 비공개 테스트 트랙으로 출시 시작**
7. 승인 뒤 **테스터** 탭의 **참여 링크**(웹/Android)를 복사해 테스터에게 보낸다. 테스터는 링크에서 "테스터 되기"를 누른 뒤 Play 스토어에서 설치한다.

### 업로드 뒤 바로 할 일

- **설정 → 앱 무결성(앱 서명)**에서 **앱 서명 키 인증서 SHA-256 지문**을 복사해 Claude에게 전달 → `.well-known/assetlinks.json`에 추가 (없으면 Play 설치본 위에 주소창이 보인다)

### 14일 규칙 (2023-11-13 이후 만든 개인 개발자 계정)

- **테스터 12명 이상이 14일 동안 계속 참여**해야 프로덕션 액세스를 신청할 수 있다
- "참여"는 테스트에 가입하고 앱을 설치한 상태를 유지하는 것. 중간에 빠지는 사람이 있을 수 있으니 15~20명을 모은다
- 테스트 중에도 업데이트는 올릴 수 있다 (14일이 다시 시작되지 않는다)

## 5. 선택 사항

- **글꼴을 앱에 넣기:** Google Fonts 요청을 없애면 개인정보처리방침의 외부 요청 항목이 사라지고, 첫 실행부터 오프라인 글꼴이 보장된다. 대신 앱 용량이 늘어난다 (한글 글꼴 2굵기 기준 수 MB). 지금 단계에서는 필요 없음
