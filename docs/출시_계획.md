# 출시 계획 (2026-11-16 개정)

이 문서는 2026-10-23에 claude.ai 문서로 작성한 「과학적 속독법 앱 출시 계획」을 지금 상황에 맞게 다시 쓴 것이다. 첫 목표일(11/13)은 지났다. 앱 개발은 거의 끝났고, 출시 일정은 **Play 개발자 계정** 단계에서 멈춰 있다.

---

## 1. 결론

- **새 목표: 12월 12일(토)경 Google Play 공개.** 조건은 세 가지다.
  1. 본인 인증이 11/20까지 끝난다.
  2. 테스터 12명 이상이 14일 동안 빠지지 않는다.
  3. 프로덕션 심사가 7일 안에 끝난다.
- 일정의 출발점은 **본인 인증이 끝나는 날**이다. 인증이 하루 늦어지면 공개일도 하루 늦어진다.
- 목표를 두 단계로 나눈다.

| 목표 | 내용 | 조건 |
|---|---|---|
| 확정 목표 | 12/5경 프로덕션 액세스 신청 완료, 스토어 정보·앱 콘텐츠 설문 모두 입력 | 우리가 일정대로 하면 됨 |
| 최선 목표 | 12/12경 일반 공개 | 인증 11/20 이내, 심사 7일 이내, 저작권 결정 |

## 5. 위험과 대응

| 위험 | 영향 | 대응 |
|---|---|---|
| 본인 인증이 늦어짐 | 모든 날짜가 같은 날수만큼 밀림 | 오늘 가입·신청. 그동안 테스터·이메일·앱 이름·저작권 문의를 먼저 끝내 둠 |
| 테스터가 12명 밑으로 줄어듦 | 신청 때 12명이 안 되면 신청 불가 | 15명 이상 모집, 5일·10일째 안부 메시지, 주 2회 업데이트 알림 |
| 테스터가 실제로 쓰지 않음 | (확인 안 된 규칙이지만) 신청이 거절될 수 있음 | 하루 한 번 훈련하도록 안내, 의견 양식으로 사용 기록 받기 |
| 첫 테스트판 검토가 늦어짐 | 14일 시작이 늦어짐 | 업로드 즉시 상태 확인, 반려되면 사유대로 바로 고침 |
| 프로덕션 심사가 7일을 넘김 | 12/12 공개 불가 | 확정 목표를 "12/5 신청 완료"로 두고, 통과하는 대로 공개 |
| 저작권 답변이 없음 | 공개 보류 가능 | 비공개 테스트는 계속 진행. 12/2에 B판(책 제목 없이) 공개 여부를 결정. 공개 여부는 권리자 답변이나 전문가 의견을 보고 정함 (Claude는 법률 판단을 하지 않음) |
| 휴대폰에서 제2·3단계 화면이 작음 | 사용자 불만 | 스토어·앱에 "태블릿 권장" 명시, 휴대폰은 가로 화면 안내 |
| 눈 깜박임 훈련에 대한 건강 우려 | 심사·리뷰 문제 | 안전 안내를 앱과 스토어 설명에 모두 넣음. 의학적 효과는 주장하지 않음 |
